# Windows Code Signing – Medilink HMIS Desktop

## Required GitHub Secrets
| Secret | Description |
|--------|-------------|
| `WINDOWS_CERTIFICATE_BASE64` | Base‑64 encoded `.pfx` file containing the Authenticode certificate **and** private key. |
| `WINDOWS_CERTIFICATE_PASSWORD` | Password for the `.pfx` (empty string if none). |
| `WINDOWS_CERTIFICATE_THUMBPRINT` *(optional)* | SHA‑1 thumbprint of the certificate – useful for logging/verification. |

## Signing script
The repository contains `src-tauri/scripts/sign-windows.ps1`. It:
1. Decodes the base64 secret into a temporary `.pfx` file.
2. Calls `signtool.exe` with SHA‑256, the certificate, and a trusted timestamp server (`http://timestamp.digicert.com`).
3. Verifies the signature.
4. Deletes the temporary file.

## CI integration (Windows runners only)
```yaml
- name: Sign Windows binaries
  if: matrix.platform == 'windows-latest'
  shell: pwsh
  env:
    WINDOWS_CERTIFICATE_BASE64: ${{ secrets.WINDOWS_CERTIFICATE_BASE64 }}
    WINDOWS_CERTIFICATE_PASSWORD: ${{ secrets.WINDOWS_CERTIFICATE_PASSWORD }}
  run: |
    # Locate the installer generated by the Tauri action (the exact name contains version & arch)
    $installer = Get-ChildItem -Path "${{ steps.desktop.outputs.projectPath }}\src-tauri\target\release\bundle\nsis\" -Filter "*.exe" | Select-Object -First 1
    if (-not $installer) { Write-Error "Installer not found"; exit 1 }
    Write-Host "Signing $($installer.FullName)"
    .\${{ steps.desktop.outputs.projectPath }}\src-tauri\scripts\sign-windows.ps1 -binaryPath $installer.FullName
```
The step runs **after** the `tauri-action` build step, ensuring the installer exists.

## Verification locally
```powershell
signtool verify /pa path\to\MedilinkHMISDesktop.exe
```
The command should report **SUCCESS** and show a timestamp.

## Security notes
- Secrets are only available on Windows runners (the `if:` guard). 
- The script never writes the certificate to the repository; it only stores a temporary file on the runner and deletes it immediately after signing.
- No secret values are printed to logs.
